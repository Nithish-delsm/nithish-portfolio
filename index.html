ShopEase: Multi-Tier E-Commerce Application on AWS

A full-stack e-commerce application built to demonstrate multi-tier cloud architecture on AWS, using Infrastructure as Code, containerization and Kubernetes orchestration. It is split into three independent tiers: a React frontend, a Node.js/Express REST API and a MySQL database on Amazon RDS.

Architecture

What I built

  • Infrastructure: VPC, subnets, route tables, RDS, ECR, EKS cluster, IAM roles and node groups, all defined in Terraform.
  • Containers: frontend and backend containerized with multi-stage Docker builds, deployed to Kubernetes with Deployment and Service manifests, using LoadBalancer services and replicated deployments.
  • Pipeline: a GitHub Actions workflow builds Docker images and pushes them to Amazon ECR on every push to main.
  • Database: MySQL 8 on Amazon RDS in a private subnet, with a schema and seed data.
  • Application: product browsing, cart, login and checkout; a REST API with JWT authentication, bcrypt password hashing and transactional order processing with stock validation.
