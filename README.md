# Nithish S — Cloud & DevOps Portfolio

A responsive static portfolio using warm ivory `#F9EBD7`, emerald `#046A38`, and vermilion `#E34222`.

## Files
- `index.html` — page content
- `style.css` — responsive styling and color system
- `script.js` — mobile navigation, scroll effects, and contact form mailto behavior
- `profile.jpg` — portfolio portrait
- `resume.pdf` — resume download
- `.nojekyll` — tells GitHub Pages to serve the static files as-is

## Publish with GitHub Pages
1. Create a GitHub repository (for example `nithish-portfolio`).
2. Upload the **contents of this folder** to the repository root; `index.html` must be at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main`, folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish in the Actions tab, then use the site URL shown in Settings → Pages.

GitHub Pages sites are public. Check the content and resume before publishing. The contact form opens the visitor's configured email app; it does not send mail through a server.
